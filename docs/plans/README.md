# docs/plans/

One Markdown file per feature, named `<short-kebab-feature>.md` (e.g.
`auth-rotation.md`, `search-pagination.md`). Each plan must follow the
section order defined in `.agents/skills/plan/SKILL.md` and end with a
`## Approved by:` line filled in by a human before implementation begins.
Superseded plans stay in this directory; do not delete them — they are
the project's design history.
